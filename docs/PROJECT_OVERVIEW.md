## 1. What the system is (one paragraph)

A simulated AUV (Gazebo Harmonic + ROS 2 Jazzy) surveys a seabed with a camera. **Onboard**, it detects objects (YOLO11n), tracks them (ByteTrack), geolocates them, fuses sightings into contacts, and a scheduler sends the most valuable information as **8-byte messages over an emulated 64 bps acoustic link** (Water Linked M64 published spec). A surface decoder sees **only** what crossed the link. We measure bandwidth used vs. video, and how much useful information (recall, latency, position error) reached the surface. Simulation only, TRL 3–4 [P §1, R §7].

**Pipeline:** camera → detector → tracker → geolocator → contact_db → scheduler → link_emulator → surface_decoder → Foxglove.

Keep runs serialized for final evaluation or address both in an isolated tooling change (NOT part of T1.3).
